1. Project Objective

The objective of this project was to understand and practise basic footprinting and information-gathering techniques using different tools available in Kali Linux.

The exercise involved gathering publicly available information about the assigned target domain, "networkwalks.com", and documenting the results.

2. Tools Used

The following six tools were used:

1. WHOIS: Used to retrieve domain registration information.
2. WhatWeb: Used to identify technologies associated with the website.
3. NSLookup: Used to query DNS records and domain information.
4. cURL: Used to retrieve HTTP response headers.
5. WAFW00F: Used to check for indications of a Web Application Firewall (WAF).
6. DNSRecon: Used to gather DNS-related information.

5. What I Learned

Through this practical exercise, I gained experience using different Kali Linux footprinting tools and learned how they help gather domain, website, HTTP and DNS information.

I also improved my command-line skills, learned how to save terminal outputs into text files, and practised documenting technical work using screenshots.

6. Conclusion

This project provided practical exposure to fundamental footprinting techniques and improved my understanding of information gathering as part of cybersecurity reconnaissance.
