# 4. MODULE 2 – ZENMAP NETWORK SCANNING (W2-PM5)

Zenmap, the graphical interface for Nmap, was used to perform network discovery on my local network.

The practical exercise involved:

- Identifying the local network subnet.
- Performing a ping scan.
- Discovering active hosts.
- Recording available IP and MAC address information.
- Generating a network topology diagram.

### Scan Summary

The recorded scan reported **28 hosts up** out of 256 IP addresses in the scanned subnet.

The saved topology PDF displays 30 IP-address entries. This is documented separately from the scan's reported host count.

### Evidence collected

The PM5-Zenmap folder contains the available scan evidence and a redacted topology PDF for public viewing.
